1 GitHub 创建仓库并上传代码

1 注册/登录 GitHub

打开 github.com，如果没有账号点击「Sign up」注册（免费）。已有账号直接「Sign in」登录。

2 创建新仓库

点击右上角 + → New repository，填写以下信息：

字段填写内容
Repository nameai-tech-frontend（或你喜欢的名称）
DescriptionAI科技要闻 · 技能知识分享 · 共同学习交流
Visibility选择 Public（公开，Cloudflare Pages 免费版需要公开仓库）
Initialize不要勾选 Add README / .gitignore / license（我们已有这些文件）

点击绿色按钮 Create repository 创建。

创建后会跳转到空仓库页面，页面上会显示仓库地址，类似：https://github.com/你的用户名/ai-tech-frontend.git，记下这个地址。
3 上传文件（手动方式 — 推荐）

在刚创建的空仓库页面：

方式 A：网页直接上传（最简单，适合不熟悉 Git 的同学）

  1. 点击页面上的 uploading an existing file 链接
  2. 将项目文件夹中的所有文件和子文件夹拖入虚线框区域
  3. 需要上传的文件清单：
ai-tech-frontend/
├── index.html          ← 必须上传
├── .gitignore          ← 必须上传
├── README.md           ← 必须上传
├── css/
│   └── style.css       ← 必须上传（注意保留 css/ 目录结构）
└── js/
    └── main.js         ← 必须上传（注意保留 js/ 目录结构）
注意：不要上传 .workbuddy/ 文件夹和 deploy-guide.html（部署指南不属于网站内容）。.gitignore 已经排除了 .workbuddy/。

在页面底部填写 commit message（如 Initial commit: AI科技前沿 · 学习交流网站），点击 Commit changes 提交。

4 上传文件（Git 命令方式 — 适合开发者）

如果已安装 Git，可在终端执行：

# 进入项目目录
cd "D:/系统D盘下载文件/260731_feige_workbuddy/2026-08-16-09-34-02"

# 初始化 Git 仓库
git init
git branch -M main

# 添加文件（.gitignore 会自动排除 .workbuddy/）
git add .

# 提交
git commit -m "Initial commit: AI科技前沿 · 学习交流网站"

# 关联远程仓库（替换为你的地址）
git remote add origin https://github.com/你的用户名/ai-tech-frontend.git

# 推送
git push -u origin main
如果推送时要求登录，GitHub 已不支持密码认证，需要使用 Personal Access Token 替代密码。
5 确认文件已上传

回到 GitHub 仓库页面，确认能看到以下结构：

📁 css/
   📄 style.css
📁 js/
   📄 main.js
📄 .gitignore
📄 README.md
📄 index.html
✅ 确认 index.html 在仓库根目录（不在子文件夹里），这点对 Cloudflare Pages 很重要。

2 Cloudflare Pages 连接仓库并部署

1 注册/登录 Cloudflare

打开 dash.cloudflare.com 注册账号（免费）。已有账号直接登录。

Cloudflare 注册不需要信用卡，免费版功能对本项目完全够用。
2 进入 Cloudflare Pages

登录后在左侧导航栏找到 Workers & Pages → 点击 Create → 选择 Pages 标签页 → 点击 Connect to Git。

3 授权 GitHub

首次使用会跳转到 GitHub 授权页面：

  1. 选择 Only select repositories
  2. 在下拉列表中选中你刚创建的 ai-tech-frontend 仓库
  3. 点击 Install & Authorize

授权完成后会自动跳回 Cloudflare。

4 配置项目（关键步骤）

选择刚才授权的仓库 ai-tech-frontend，点击 Begin setup，按以下表格填写：

配置项填写值说明
Project name ai-tech-frontend 将作为域名的一部分
Production branch main 主分支，推送代码到 main 自动触发部署
Framework preset None 纯静态网站，无框架
Build command 留空 不需要构建，直接部署源文件
Build output directory /（或留空） 输出目录就是仓库根目录
Root directory 留空 使用仓库根目录
最重要：Build command 必须留空！这不是 Next.js/React 项目，不需要 npm run build。
5 环境变量（可选）

本项目不需要任何环境变量，直接跳过这一步。

6 点击 Save and Deploy

点击页面底部的 Save and Deploy 按钮。Cloudflare 会开始第一次构建部署。

部署过程通常 30 秒 ~ 1 分钟。页面会显示实时日志，看到 Success! Your site is deployed 就完成了。

✅ 部署成功后，页面会显示你的网站地址，格式为：
https://ai-tech-frontend.pages.dev

3 验证部署与自定义域名

1 验证网站

点击部署成功页面上的访问链接，或在浏览器输入 https://你的项目名.pages.dev，确认网站正常打开。

检查清单：

  • ✅ 页面正常加载，样式正确
  • ✅ 明暗主题切换正常
  • ✅ Chart.js 图表正常渲染
  • ✅ 移动端响应式布局正常
  • ✅ HTTPS 证书已自动启用
2 自定义域名（可选）

如果你有自己的域名，可以绑定到 Cloudflare Pages：

  1. 进入 Cloudflare Pages 项目 → Custom domains → Set up a custom domain
  2. 输入你的域名（如 www.yoursite.com）
  3. 如果域名已托管在 Cloudflare，DNS 记录会自动添加
  4. 如果在其他注册商，按提示添加 CNAME 记录指向 你的项目名.pages.dev
  5. 等待 DNS 生效（通常几分钟到几小时），SSL 证书自动签发
3 后续更新网站

以后每次修改代码后，只需要把更新的文件推送到 GitHub 的 main 分支，Cloudflare Pages 会自动检测并重新部署，无需手动操作。

网页上传方式：进入 GitHub 仓库 → 点击对应文件 → 编辑（铅笔图标） → 修改 → Commit changes。
Git 命令方式：git add . && git commit -m "更新说明" && git push

常见问题

Q: 部署后页面空白 / 样式丢失？

检查 GitHub 仓库中 css/ 和 js/ 文件夹是否上传成功，文件路径是否正确。在浏览器按 F12 打开开发者工具 → Console / Network 面板查看是否有 404 报错。

Q: Chart.js 图表不显示？

Chart.js 通过 CDN 加载，确认部署环境能正常访问 cdn.jsdelivr.net。如果需要离线使用，将 Chart.js 下载到本地 js/ 目录，修改 index.html 中的 <script src> 为本地路径。

Q: GitHub 上传时提示文件太多？

GitHub 网页上传最多 100 个文件。本项目只有 5 个文件，不会触发限制。如果后续文件增多，建议改用 Git 命令推送。

Q: Cloudflare Pages 免费版有什么限制？

免费版包含：每月 500 次构建、无限请求、无限带宽、无限站点。对于个人网站完全够用，不需要付费。

Q: 能否绑定多个域名？

可以。在 Cloudflare Pages → Custom domains 中可以添加多个域名，每个域名都会自动获得 SSL 证书。

Q: 如何查看部署历史和回滚？

在 Cloudflare Pages 项目页面 → Deployments 标签页可以看到所有部署记录。点击任意历史部署右侧的 ... → Rollback to this deployment 即可回滚。
