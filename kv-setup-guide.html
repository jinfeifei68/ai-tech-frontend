KV 后端管理系统部署指南

Cloudflare Pages + Functions + KV — 从零配置到管理后台上线

前置条件 第一步：创建 KV 第二步：绑定 KV 第三步：设置密码 第四步：上传代码 第五步：初始化数据 第六步：验证 常见问题

架构说明：本次升级在原有静态网站基础上增加了 Cloudflare Functions API 和 KV 存储层。管理后台通过 API 读写 KV，前台页面自动从 KV 加载内容。无需重新构建，改完即时生效。

前置条件

  • 已有 Cloudflare 账号（免费版即可）
  • 网站已通过 Cloudflare Pages 部署（或即将部署）
  • GitHub 仓库已创建

1 创建 KV 命名空间

  1. 登录 Cloudflare Dashboard
  2. 左侧菜单找到 Workers & Pages → 点击 KV 标签
  3. 点击 Create a namespace 按钮
  4. 名称填写：CONTENT_KV
  5. 点击 Add 创建完成

创建后你会看到一个 Namespace ID，记下来备用（绑定时会用到）。

2 绑定 KV 到 Pages 项目

  1. 进入 Workers & Pages → 找到你已部署的 Pages 项目
  2. 点击项目名称进入详情页
  3. 点击 Settings 标签
  4. 找到 Functions 区域 → KV namespace bindings
  5. 点击 Add binding
  6. 按以下信息填写：
配置项填写值
Variable nameCONTENT_KV
KV namespace选择第一步创建的 CONTENT_KV
EnvironmentProduction（同时建议添加 Preview）

注意：Variable name 必须是 CONTENT_KV，代码中通过 env.CONTENT_KV 访问。名称不匹配会导致 API 返回 503 错误。

3 设置管理员密码

  1. 仍在 Pages 项目的 Settings 页面
  2. 找到 Environment variables 区域
  3. 点击 Add variable
  4. 按以下信息填写：
配置项填写值
Variable nameADMIN_PASSWORD
Value你的管理密码（如 MySecurePass2026）
EnvironmentProduction

安全建议：密码请使用字母+数字组合，至少 12 位。不要使用常见密码。此密码用于登录管理后台 /admin.html。

4 上传代码到 GitHub

将以下文件上传到你的 GitHub 仓库（如果已连接 Cloudflare Pages，推送后自动触发部署）：

需要上传的文件/目录：

你的仓库/ ├── index.html ← 已有（已修改，支持动态加载） ├── admin.html ← 新增（管理后台页面） ├── css/ │ ├── style.css ← 已有 │ └── admin.css ← 新增（管理后台样式） ├── js/ │ ├── main.js ← 已有（已修改，支持动态加载） │ └── admin.js ← 新增（管理后台逻辑） ├── functions/ │ └── api/ │ └── [[catchall]].js ← 新增（API 接口） ├── wrangler.toml ← 新增（本地开发配置） ├── .gitignore ← 已有 └── README.md ← 已有

上传方式一：网页拖拽（简单）

  1. 打开你的 GitHub 仓库页面
  2. 点击 Add file → Upload files
  3. 将上述文件拖入（注意 functions/api/ 目录结构需要先在仓库里创建文件夹）
  4. 填写 commit message，点击 Commit changes

上传方式二：Git 命令（推荐）

cd 你的项目目录 git add -A git commit -m "feat: 添加 KV 后端管理系统" git push origin main

推送后 Cloudflare Pages 会自动触发构建部署。等待 30-60 秒后，Functions API 即可在生产环境使用。

5 初始化数据

  1. 部署完成后，访问 https://你的域名.pages.dev/admin.html
  2. 输入第三步设置的管理员密码，点击登录
  3. 首次登录后，KV 中还没有内容数据
  4. 点击右上角 「初始化数据」 按钮
  5. 确认后，系统会自动将种子数据写入 KV（包括 6 篇文章、6 个技能、5 个视频等）
  6. 看到「数据初始化完成」提示后，左侧导航可看到各内容列表

初始化后，前台首页刷新即可看到从 KV 动态加载的内容。之后所有内容修改都在管理后台完成，无需改代码。

6 验证完整流程

  1. 访问前台首页，确认页面正常显示
  2. 打开管理后台，编辑一篇文章标题，保存
  3. 刷新前台首页，确认标题已更新
  4. 在管理后台新增一篇文章，保存
  5. 刷新前台首页，确认新文章出现在列表最前面
  6. 测试删除功能，确认删除后前台同步更新

如果以上步骤全部通过，KV 后端管理系统已完全就绪！

常见问题

Q1: 登录页显示「无法连接服务器」

API 未部署成功。检查 functions/api/[[catchall]].js 文件是否已上传，目录结构是否正确。在 Cloudflare Pages 的 Functions 标签页可以看到部署日志。

Q2: 登录提示「管理员密码未设置」

环境变量 ADMIN_PASSWORD 未配置或名称不匹配。回到第二步检查 Settings → Environment variables。

Q3: API 返回 503「KV 未绑定」

KV 命名空间未绑定或 Variable name 不是 CONTENT_KV。回到第二步检查 Settings → Functions → KV namespace bindings。

Q4: 前台页面还是显示旧的静态内容

可能是浏览器缓存。尝试 Ctrl+Shift+R 强制刷新。也可能是 API 未部署成功，用浏览器开发者工具 Network 面板检查 /api/content?type=all 请求是否返回正常。

Q5: 管理后台修改了内容但前台没变化

前台页面会请求 /api/content 获取最新数据。如果没变化，检查 API 是否返回了新数据。Cloudflare KV 写入后可能有几秒的传播延迟。

Q6: 本地开发如何测试 Functions？

安装 Wrangler CLI 后运行：

npx wrangler pages dev . --kv CONTENT_KV --binding ADMIN_PASSWORD=your_password

这会在本地启动一个服务器，支持 Functions 和 KV 的完整功能。

Q7: 如何修改管理员密码？

在 Cloudflare Pages Settings → Environment variables 中修改 ADMIN_PASSWORD 的值即可。修改后需要重新登录。
